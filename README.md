# Модель для прогнозирования категории возраста пользователей на основе их поведения в цифровой среде
Проект был выполнен в ходе обучения в Яндекс.Практикуме, профессия "Специалист по Data Science".

#### Краткое описание проекта
Необходимо построить модель многоклассовой классификации, которая предсказывает категорию возраста пользователя на основе его поведения в цифровой среде. Результат модели станет основой для реализации замыслов маркетологов некоторой IT-компании о том, чтобы показывать рекламу на целевую аудиторию определённого возраста и снизить риски показа рекламы для взрослых несовершеннолетним.

#### Реализованные этапы проекта
- подготовлена среда и библиотеки для работы;
- проведен исследовательский анализ данных;
- предобработаны данные;
- обучены базовые модели и проведен для них расчет метрик;
- созданы и отобраны признаки;
- подобраны гиперпараметры моделей;
- подготовлены артефакты модели для внедрения;
- сделаны выводы о результатах работы.

#### Основной использованный в проекте стек технологий:
- **Язык**: Python
- **Обработка данных**: pandas, NumPy
- **Машинное обучение**: scikit-learn
- **Визуализация**: matplotlib, seaborn
- **Модели**: LogisticRegression, SVC, LinearSVC (DummyClassifier в качестве базовой модели)
